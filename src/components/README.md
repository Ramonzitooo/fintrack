# UI Components (`src/components`)

## Overview
Modular React 19 views implementing the 6 canonical financial tabs, the technical audit diagnostic panel, and the 15 interactive modal sheets with Apple Fluid Design gesture physics and WCAG 2.2 AA accessibility.

## Interface
- `[src/components/OverviewTab.tsx:OverviewTab]`: `React.FC<OverviewTabProps>` (`{ state: AppState, daysUntilNextPayday: number, nextPaydayFormatted: string, onNavigate: (tab: string) => void, onOpenPaydayModal: () => void, onOpenAporteModal: (caixinhaId: string) => void }`).
- `[src/components/BanksAndGoalsTab.tsx:BanksTab]`: `React.FC<{ state: AppState; onOpenNewBank: () => void; onOpenPixTransfer: () => void; onAdjustBankBalance: (bankId: string) => void; onDeleteBank: (bankId: string) => void; onUpdateCdiRate: (newRate: number) => void }>`.
- `[src/components/BanksAndGoalsTab.tsx:GoalsTab]`: `React.FC<{ state: AppState; onOpenNewGoal: () => void; onOpenFireModal: () => void; onOpenAporteModal: (caixinhaId: string) => void; onOpenWithdrawModal: (caixinhaId: string) => void; onDeleteGoal: (caixinhaId: string) => void; onUpdateFireParams: (swrPct: number, realReturnPct: number) => void }>`.
- `[src/components/PayrollAndCardsTab.tsx:PayrollTab]`: `React.FC<PayrollTabProps>` (`{ state: AppState, onAddProvento: (nome: string, valor: number) => void, onUpdateProvento: (id: string, field: 'nome' | 'valor', val: string | number) => void, onRemoveProvento: (id: string) => void, onAddDesconto: (nome: string, valor: number) => void, onUpdateDesconto: (id: string, field: 'nome' | 'valor', val: string | number) => void, onRemoveDesconto: (id: string) => void, onApplyOfficialTaxes: (inss: number, irrf: number) => void, onOpenReceiveSalaryModal: () => void, onSavePayrollToHistory: () => void, onLoadHistoryPayroll: (id: string) => void, onDeleteHistoryPayroll: (id: string) => void }`).
- `[src/components/PayrollAndCardsTab.tsx:CardsTab]`: `React.FC<CardsTabProps>` (`{ state: AppState, onOpenNewCard: () => void, onRequestEditCardInvoice: (cardId: string, cardNome: string, currentInvoice: number) => void, onDeleteCard: (cardId: string) => void }`).
- `[src/components/ExpensesTab.tsx:ExpensesTab]`: `React.FC<ExpensesTabProps>` (`{ state: AppState; onChangeMonth: (delta: number) => void; onGoToCurrentMonth: () => void; onOpenNewExpenseModal: () => void; onOpenTemplateModal: () => void; onOpenPayExpenseModal: (expenseId: string) => void; onRefundExpense: (expenseId: string) => void; onEditExpenseAmount: (expenseId: string) => void; onDeleteExpense: (expenseId: string) => void; onSyncTemplateToMonth: () => void; onRequestEditEnvelope?: (key: 'supermercado' | 'lazer' | 'combustivel', title: string, currentTotal: number) => void; onUpdateEnvelope: (key: 'supermercado' | 'lazer' | 'combustivel', total: number, cadencia: 'semanal' | 'quinzenal' | 'mensal' | 'fds') => void; onAddDebt: (debt: Omit<DebtItem, 'id'>) => void; onDeleteDebt: (id: string) => void }`).
- `[src/components/AuditDiagnosticView.tsx:AuditDiagnosticView]`: `React.FC<{ state: AppState; onNavigate: (tab: string) => void }>`.
- `[src/components/AppModals.tsx:ActiveModalType]`: Exported union type of modal identifiers (`null | 'newBank' | 'pixTransfer' | 'newGoal' | 'fireConfig' | 'aporteGoal' | 'withdrawGoal' | 'newCard' | 'newExpense' | 'payExpense' | 'templateModal' | 'receiveSalary' | 'paydayConfig' | 'backup' | 'cmdk' | 'quickEditValue'`).
- `[src/components/AppModals.tsx:QuickEditConfig]`: Exported interface `{ title: string; description: string; initialValue: number; allowNegative?: boolean; onConfirm: (val: number) => void }`.
- `[src/components/AppModals.tsx:AppModals]`: Exported `React.FC<AppModalsProps>` rendering the modal dialog backdrop, 1:1 Pointer Events sheet drag handle, and 15 modal views.

## Invariants
- `[src/components/OverviewTab.tsx:OverviewTab]`: Reconciles `saldoLivre = totalBancos - contasPendentes` and `patrimonioLiquido = totalBancos + totalCaixinhas - contasPendentes - totalDividas`; classifies cash health as `'Caixa Negativo'` (`< 0`), `'Caixa Apertado'` (`< 300`), or `'Caixa Saudável'` (`>= 300`).
- `[src/components/OverviewTab.tsx:OverviewTab]`: Bounds `diariaSegura` base (`baseParaDiaria`) to `Math.min(sobraPrevistaMes, Math.max(0, saldoLivre))` when `salarioLiquido > 0` (or `Math.max(0, saldoLivre)` otherwise) where `sobraPrevistaMes = Math.max(0, salarioLiquido - despesasMesTotal - totalAportesPlanejados)`, and divides by `daysUntilNextPayday` when `> 0`.
- `[src/components/BanksAndGoalsTab.tsx:BanksTab]`: Falls back to `10.75%` annual CDI when `state.configuracoes.taxaCdiAnual` is falsy, computes yield only for banks with `b.rendeJuros === true` using `(b.pctCDI || 100)%` CDI and `17.5%` IR, and guards `pctRendendo` against division by zero when `totalBancos <= 0`.
- `[src/components/BanksAndGoalsTab.tsx:GoalsTab]`: Uses `budget.essentialsTotal` as `custoEssencial` if `> 0`, otherwise falls back to current month expenses; defaults FIRE parameters to `swrPct = 4.0` and `realReturnPct = 5.0` when falsy; clamps goal progress `pct` to `[0, 100]`.
- `[src/components/PayrollAndCardsTab.tsx:PayrollTab]`: Clamps `dependents` and `antiImpulsoPreco` to `>= 0`; restricts `antiImpulsoJornada` selector to `{220, 200, 180, 150}` hours/month; computes `valorHora = liquido > 0 ? liquido / antiImpulsoJornada : 0`.
- `[src/components/PayrollAndCardsTab.tsx:CardsTab]`: Defaults `limiteTotal` to `5000` when falsy, clamps credit utilization `usoPct` to `[0, 100]`, and clamps simulator inputs `simValor`, `simDesconto`, and `simTaxaCdi` to `>= 0`.
- `[src/components/ExpensesTab.tsx:ExpensesTab]`: Clamps `pctQuitado` and envelope `pctUsed` to `[0, 100]`; maps routine envelope spending by category (`'supermercado'` -> `'Alimentação'`, `'lazer'` -> `'Lazer' | 'Assinaturas'`, `'combustivel'` -> `'Transporte'`); sorts debts by descending `taxaJurosMensal` for `'avalanche'` and ascending `saldoDevedor` for `'snowball'`.
- `[src/components/AuditDiagnosticView.tsx:AuditDiagnosticView]`: Falls back to `10.75%` annual CDI when `state.configuracoes.taxaCdiAnual` is falsy and falls back to `2500` essential monthly expenses in `calculateFireProjection` when `budget503020.essentialsTotal` is `0`.
- `[src/components/AppModals.tsx:handleSheetPointerMove]`: Sheet drag velocity is smoothed with an exponential moving average (`velocityY * 0.35 + instantVy * 0.65`); upward drag (`rawDelta < 0`) applies `rubberbandOffset(rawDelta, 320, 0.55)` while downward drag translates 1:1.
- `[src/components/AppModals.tsx:handleSheetPointerUp]`: Sheet dismisses via `onClose()` only when `shouldDismissSheetOnRelease(dragOffsetY, dragStateRef.current.velocityY, 110)` is `true`; otherwise `dragOffsetY` resets to `0`.
- `[src/components/AppModals.tsx:AppModals]`: In `'quickEditValue'` `onSubmit`, input is clamped via `Math.max(0, num)` unless `quickEditConfig.allowNegative` is `true`, and rounded to 2 decimal places.

## Side Effects
- `[src/components/OverviewTab.tsx:OverviewTab]`: Reads system clock via `new Date()` for goal completion projections and triggers parent navigation/modal callbacks (`onNavigate`, `onOpenPaydayModal`, `onOpenAporteModal`).
- `[src/components/BanksAndGoalsTab.tsx:BanksTab]`: Triggers parent callbacks `onUpdateCdiRate`, `onOpenPixTransfer`, `onOpenNewBank`, `onAdjustBankBalance`, and `onDeleteBank`.
- `[src/components/BanksAndGoalsTab.tsx:GoalsTab]`: Triggers parent callbacks `onOpenAporteModal`, `onOpenWithdrawModal`, `onOpenFireModal`, `onUpdateFireParams`, `onOpenNewGoal`, and `onDeleteGoal`.
- `[src/components/PayrollAndCardsTab.tsx:PayrollTab]`: Mutates local state (`antiImpulsoPreco`, `antiImpulsoJornada`, `dependents`, `historyFilter`) and invokes parent payroll/history callbacks.
- `[src/components/PayrollAndCardsTab.tsx:CardsTab]`: Mutates local simulator state (`simValor`, `simDesconto`, `simParcelas`, `simTaxaCdi`) and invokes parent card lifecycle/invoice callbacks.
- `[src/components/ExpensesTab.tsx:ExpensesTab]`: Mutates local filter/debt form state and invokes parent expense, template, envelope, and debt callbacks.
- `[src/components/AuditDiagnosticView.tsx:AuditDiagnosticView]`: Triggers parent navigation callback `onNavigate('contracheque' | 'despesas' | 'cartoes')`.
- `[src/components/AppModals.tsx:AppModals]`: Captures and restores `document.activeElement` focus across modal open/close cycles (`previousFocusRef`), acquires/releases DOM pointer capture (`setPointerCapture` / `releasePointerCapture`), and invokes parent state mutation and file export/import callbacks.
